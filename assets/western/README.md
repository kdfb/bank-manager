# Wild West Asset Atlases

These transparent PNG atlases were generated with the built-in OpenAI image-generation tool, then processed locally with the Codex image-generation skill's chroma-key removal helper.

## Character atlas

File: `characters-atlas.png`  
Canvas: 1536 × 1024

Prompt summary:

> A polished pixel-art-inspired Wild West bank character atlas with five full-body, three-quarter top-down sprites: a green-waistcoated bank manager, burgundy-waistcoated teller, rancher, frontier merchant, and well-dressed traveler. Consistent scale, warm 1850s palette, crisp small-game readability, flat magenta chroma background, no shadows, text, logos, modern clothing, or weapons.

Source rectangles are defined in `js/branch.js`.
